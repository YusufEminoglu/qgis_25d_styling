about=QGIS 2.5D Styling performs one focused task: producing publication-ready 2.5D building symbology. Use an existing polygon layer or explicitly download bounded OSM building footprints. OSM building:levels values drive floor counts; missing values use a visible, configurable three-floor default. The compact right dock provides three renderers, projection and material controls, 10 curated 02CartoLab-derived themes, 23 per-floor palettes (each theme's own matching gradient plus 13 standalone palettes), live preview, previous-style restoration, and QML import/export. A single Processing algorithm applies styling headlessly. No pip dependencies are required. Repository: https://gitlab.com/geospacephilo/qgis_25d_styling
